# YESDELIGHT Stock Studio

미리캔버스 디자인허브 · 툴디에 올릴 **요소**(배경 · PNG · SVG · 동영상) 작업실. 혼자 쓰는 웹앱이고, 데이터는 내 브라우저와 내 구글 드라이브에만 저장돼요.

## 메뉴
1. **홈** — 오늘 만들 것 / 올릴 것 / 심사 결과 확인(기다린 날짜), 다가오는 2주(완료는 접어둠), 지금 만들어야 할 시즌
2. **캘린더·아이디어**
   - 월간 달력, 기간 테마(예: 크리스마스 주간), 날짜별 작업(완료 숨기기), 한국 시즌 표시
   - 아이디어 보관함: 직접 메모 / ✨ AI 아이디어 추천 / ✨ 트렌드 서치(웹 검색) → 달력 날짜로 **끌어다 놓기**(모바일은 📅 버튼)
   - ✨ AI로 이 달 캘린더 짜기
3. **작업대** — 1 기획(✨ 프롬프트, 기록 저장) → 2 이미지(API 생성 또는 파일 업로드·붙여넣기) → 3 다듬기 → 4 검수·저장(✨ 제목·키워드) → 같은 주제로 다음 거 만들기
   - PNG/SVG: 배경 제거, 흰 테두리 제거, 잔여 픽셀 제거, 가장 큰 덩어리만 남기기, **여백 없이 크롭**, 최소 해상도까지 확대, 120dpi 기록
   - SVG: 색상 5개 이하로 정리, 색상 잠금(팔레트 직접 지정), 크랙 방지 선, 용량 150KB 확인
   - 배경: 16:9 · 9:16 · 1:1 · 4:5 · 4:3 · 3:4 · A4 비율 크롭, 2500px 이상, JPG 120dpi
   - 동영상: MP4 길이(30초)·용량(120MB) 확인
   - 검수: 자동 검수 + ✨ AI 비전 검수 + 직접 확인 체크리스트. **전부 통과해야** “업로드 준비 완료”
   - 다운로드, ☁️ Drive `[Miri] Stock/타입/연-월/`에 저장
4. **보관함** — 타입·상태별 보관함. 올리는 사이트(디자인허브·툴디·Adobe Stock, 설정에서 추가)마다 심사 상태(안 올림 → 심사 중 → 판매 중/거부)와 거부 사유를 따로 기록, 사이트 필터로 “툴디에 아직 안 올린 것” 보기, 한꺼번에 기록
5. **통계·수익** — 진행 흐름, 사이트별 심사 대기 일수, 사이트별·타입별 승인률·수익, 잘 되는 주제, 거부 사유 TOP, 월별 수익 기록

단축키: `N` 새 요소 · `1`~`5` 메뉴 · `?` 단축키 보기 · 작업대에서 `⌘/Ctrl+Enter` 다음 단계, `⌘/Ctrl+S` 저장. 설정에서 다크 모드.

규칙 전체는 [RULES.md](RULES.md) (앱 안의 📏 규칙 메뉴에서도 볼 수 있어요).

## AI 연결
- **구독 계정 수동 모드(기본)**: ChatGPT Plus · Gemini Pro · Claude Pro는 API가 포함되지 않아요. 앱이 규칙을 넣은 프롬프트를 만들어 주면 📋 복사 → 채팅에 붙여넣기 → 답변을 다시 붙여넣기 하면 자동으로 정리돼요.
- **API 자동 모드**: 설정에 API 키(사용량 과금)를 넣으면 버튼 한 번으로 실행. 글·기획·검수는 Claude / ChatGPT / Gemini 중 선택, 이미지 생성은 OpenAI 또는 Gemini. 트렌드 서치는 각 AI의 웹 검색을 사용.
- 키는 이 브라우저 localStorage에만 저장돼요.

## Google Drive 연결 (선택)
1. [Google Cloud Console](https://console.cloud.google.com/) → 새 프로젝트 → **Google Drive API** 사용 설정
2. OAuth 동의 화면: 외부 / 테스트 모드, 테스트 사용자에 내 계정 추가
3. 사용자 인증 정보 → OAuth 클라이언트 ID(웹 애플리케이션) → 승인된 JavaScript 원본에 앱 주소 추가
   (예: `https://yesdelight.github.io`, 로컬은 `http://localhost:5173`)
4. 앱 ⚙️ 설정에 클라이언트 ID 입력 → Drive 연결. `[Miri] Stock` 폴더 ID는 미리 들어가 있어요.
